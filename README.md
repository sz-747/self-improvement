# Self Improvement

Self Improvement is an agent skill for improving software based on evidence from how it runs and how people experience it.

Use it to set up replayable logs, review the previous 24 hours, rank problems by expected impact, make changes within the project's authority, and measure what changed. It supports local logs; sending telemetry to a remote service is optional.

The skill separates observation from action. It asks the agent to trace user intent through internal work to the visible result, report missing evidence plainly, and leave a change's benefit pending until enough comparable evidence exists. It does not install an agent runner, grant permission to change or release software, or prove that an application is better without outcome evidence.

The package contains the skill entry point and focused references for instrumentation, daily review, improvement work, aggregate analysis, and acceptance scenarios. It has no automated test suite; follow the acceptance checks in the skill when applying it to an application.
